# GOLDENFALCONE — HOME PAGE COMPLETE REPORT

## Project Overview

The Goldenfalcone home page (`app/(site)/page.tsx`) serves as the flagship landing experience for the premium diversified business brand. It showcases the brand's four core values, three primary business ventures, and a compelling narrative that connects them all under one vision.

The home page is composed of these sections (in order of appearance):

1. **HomeHero** — Hero section with animated tilt effect, emblem geometry, spark particles, and CTA
2. **BrandIntro** — Introduction with values diagram, quote, and gold rule separator
3. **Ventures** — Interactive hexagon carousel of business divisions
4. **BrandValues** — Five core values displayed in a staggered grid
5. **WhyGoldenfalcone** — (Currently commented out) Five reasons to choose Goldenfalcone
6. **HomeCta** — (Currently commented out) Secondary CTA section

Note: `WhyGoldenfalcone` and `HomeCta` are currently commented out in `app/(site)/page.tsx` but their components remain fully implemented.

## 1. HomeHero — Hero Section

**File**: `components/sections/home/HomeHero.tsx`

### Visual Design
- **Background**: `bg-forest` (deep forest green `#062F25`)
- **Overlay elements**:
  - Lux glow: `radial-gradient` semi-transparent gold at `-right-[12%] top-[-8%]`
  - Bottom radial: `radial-gradient` at `bottom-[-25%] left-[-15%]`
  - 12 animated "lux-spark" gold dots positioned across the hero
- **Emblem geometry**: Central golden circle with rotating lines (72 ticks, 5° increments)
- **Pointer tilt effect**: When mouse moves over the hero, the content tilts subtly via `rotateX`/`rotateY` springs driven by `useMotionValue`
- **Reduced motion**: All tilt animation respects `prefers-reduced-motion` — reduces to static state

### Layout Structure (Grid)
| Element | Desktop (lg) | Mobile |
|---------|-------------|--------|
| Main content area | `lg:col-span-7` | Full width |
| Emblem/geometry | `mx-auto aspect-square w-full max-w-[21rem] sm:max-w-md lg:col-span-5` | Centered, responsive sizing |

### Typography
| Element | Style |
|---------|-------|
| Eyebrow | `text-[0.62rem] leading-relaxed text-gold` |
| Main headline | `text-[3.15rem] leading-[1] xs:[3.6rem] sm:text-[3.6rem] xl:[6.1rem]` — lines revealed with `TextReveal`, last line italic `text-champagne` |
| Description | `text-base leading-relaxed text-ivory/75 sm:text-lg` |

### CTA Buttons
| Button | Purpose | Styles |
|--------|---------|--------|
| Primary | "Explore Our Businesses" | Full `AnimatedButton`, linked to `#businesses` |
| Secondary | "Discover Goldenfalcone" | `variant="outline-light"`, linked to `/about` |

### Business Navigation (below headline)
- Grid of 4 division links (spices, mentorship, staffing + digital-solutions implied)
- Each: `text-sm leading-snug text-ivory/85 hover:text-champagne`
- Shows number (01/02/03) + title
- Used to quickly navigate to divisional routes

### Motion & Animation
- **Spark particles**: Pre-positioned with `animationDelay` ranging 0–5.8s, continuous subtle movement
- **Emblem rotation**: `motion.circle` with `pathLength` animation (2.2s duration, `easeLux`)
- **Text reveals**: `TextReveal` with `easeLux` staggered delays (0.2, 0.3, 0.75, 0.9s)
- **Emblem tilt**: Pointer-driven `rotateX`/`rotateY` springs (stiffness: 60, damping: 18)
- **All transitions**: Use the shared `easeLux` cubic-bezier `[0.22, 1, 0.36, 1]`

### Data Flow
- Receives from `HomePage`:
  - `title: string[]` (hero title lines, e.g. `["One Vision.", "Four Dimensions of Business."]`)
  - `description: string` (hero subtitle text)
  - `primaryCta: string` (e.g. `"Explore Our Businesses"`)
  - `secondaryCta: string` (e.g. `"Discover Goldenfalcone"`)
  - `logo: string` (emblem image URL)
  - `ventures: { key, number, title, href }[]` (4 divisions from `lib/content.ts`)

## 3. Ventures — Business Carousel

**File**: `components/sections/home/Ventures.tsx`

### Position & Background
- `id="businesses"`
- `bg-forest-deep` (darker forest green)
- `py-20 sm:py-28` (padding)
- `scroll-mt-20` (offset for header)

### Layout Structure
- **VenturesHeader**: 
  - Eyebrow "Our Business Ventures" + champagne text
  - Heading "Four Dimensions., One Vision." (revealed via TextReveal)
  - Description paragraph: "Discover the diverse business ventures of Goldenfalcone..."
- **CardCarousel**: Interactive hexagon carousel with 3-mode layout

### CardCarousel Mechanics
- **State**: `activeIndex` (0, 1, or 2 for 3 divisions at a time)
- **Layout**: 
  - Centre card: full raised state (`scale: 1`, `opacity: 1`, z-index: 3)
  - Side cards: scaled down (`scale: 0.86`), opacity `1` or `0`, pointer-events-none
  - Positions: `x: -50 + offset * 78%` where offset = `(i - activeIndex + count + 1) % count - 1`
- **Navigation**:
  - Left/right arrows (`ArrowLeft`/`ArrowRight` key support, plus click)
  - Dot indicators showing all 4 divisions with `aria-current={i === activeIndex ? "true" : undefined}`
  - Panning support: horizontal swipe/pan to navigate
- **Looping**: Index wraps around via modulo arithmetic

### Card Design (HexBadge + Card)
| Element | Style |
|---------|-------|
| **HexBadge** | Tinted glass hexagon (`points: M44,6.5 Q50,3...`) with division icon in center, ivory text number |
| **Card container** | `rounded-3xl border bg-forest p-3` (active: `border-ivory/25 shadow-[0_40px_70px_-25px_rgba(0,0,0,0.85)]`)
- Image: `object-cover` with subtle `motion-safe:group-hover:scale-[1.04]`
- Gradient overlay: `bg-gradient-to-t from-forest-deep/90 via-forest-deep/35 to-forest-deep/10`
- Gold linear accent: `bg-[linear-gradient(115deg,rgba(255,255,255,0.28)_0%,...)]`
- HexBadge with division icon + number
- Title: `text-[1.85rem] leading-[1.1] text-ivory sm:[2.2rem]`
- Description: `text-sm leading-relaxed text-ivory/75 sm:[0.95rem]`
- CTA: `AnimatedButton` with outline-light variant

### Motion & Animation
- **Card entrance**: `initial` → `animate` with `easeLux` over 0.7s, translating x by `78%` increments, scaling
- **Hover image zoom**: `motion-safe:group-hover:scale-[1.04]`
- **Arrow hover**: `border-champagne/40 text-ivory → border-gold bg-gold text-forest`
- **Dot indicators**: `h-1 rounded-full transition-all duration-500` → `w-7 bg-gold` when active

### Data Flow
- **Inline data** (not from CMS): `businessDivisions` array with 3 divisions:
  1. **Spices** (Leaf icon) — `/spices`
  2. **Trading Mentorship** (GraduationCap icon) — `/trading-mentorship`
  3. **Salon Staffing** (Scissors icon) — `/salon-staffing`
- Each has: `key, icon, title, description, href, cta, image, imageAlt`
- Used independently of CMS state

### Accessibility
- `role="group"` + `aria-roledescription="carousel"` + `aria-label="Our business ventures"`
- `aria-live="polite"` announcing `Showing X of Y: DivisionTitle`
- Keyboard: ArrowLeft/ArrowRight navigation, dot indicator clicks
- `inert` prop on non-active cards to remove from DOM tab order

## 7. Data Architecture & CMS Integration

### Source of Truth
| Data Type | Source | Fallback |
|-----------|--------|----------|
| Hero title/description | CMS `SiteContent.home` | `defaults.ts` hardcoded |
| Intro title/lead/body | CMS `SiteContent.home` | `defaults.ts` hardcoded |
| CTA title/text/button | CMS `SiteContent.cta` | `defaults.ts` hardcoded |
| Brand values | CMS `SiteContent.values` + `lib/site.ts` | `defaults.ts` + `lib/content.ts` |
| Business divisions | `lib/content.ts` + CMS descriptions | `lib/content.ts` raw data |
| Site config (logo, contacts) | `lib/site.ts` + CMS `getSiteConfig()` | `site.logo` emblem, env vars for contacts |
| Division descriptions (admin-editable) | CMS `getDivisions()` | `lib/content.ts` original descriptions |

### Caching & Performance
- `getSiteContent()`: `unstable_cache` with `revalidate: 3600` (1 hour)
- `getDivisions()`: cached within `getSiteContent()`
- `getSiteConfig()`: cached with `revalidate: 3600`
- All public data has fallback to `defaultContent`/`defaultSettings` if MongoDB unavailable

### Type Safety
- `SiteContent` schema validated via `siteContentSchema` from `lib/admin/schemas`
- Type-safe `getSiteContent()` returns `Content` type
- `lines()` utility safely splits `\n`-separated headings into display lines

## 9. Motion Design & Animation Quality

### Principles Applied
- ✅ **Short and responsive** — all transitions under 2.2s
- ✅ **Natural easing** — `easeLux` [0.22, 1, 0.36, 1] throughout
- ✅ **No excessive bounce** — spring physics used sparingly (tilt effect only)
- ✅ **No large sliding distances** — carousel offsets in 78% increments
- ✅ **No flicker** — intersection observer via `viewportOnce` for GoldRule
- ✅ **Respects `prefers-reduced-motion`** — tilt disabled, animations simplified
- ✅ **Shared motion system** — all components use `easeLux`, `revealTransition`, `stagger` from `components/animations/motion.ts`

### Key Animations
1. **Spark particles**: Pre-staggered `animationDelay` 0–5.8s, continuous
2. **Emblem rotation**: 2.2s pathLength animate, `easeLux` with 0.2s delay
3. **Text reveals**: `TextReveal` with `easeLux` and incremental delays (0.2, 0.3, 0.75, 0.9s)
4. **Card carousel**: 0.7s `easeLux` translate/scale based on active state
5. **GoldRule**: `viewportOnce` intersection → self-drawing over 1.4s
6. **Pointer tilt**: Spring-driven `rotateX`/`rotateY` (stiffness 60, damping 18)
7. **Value icons**: `group-hover` translate-y-1 with 500ms ease

## 10. Accessibility Summary

| Feature | Implementation |
|---------|---------------|
| **Reduced motion** | `useReducedMotion()` disables pointer tilt; all `useMotionValue` animations simplified |
| **Keyboard navigation** | Carousel: ArrowLeft/ArrowRight, dot clicks; Arrows have `aria-label` |
| **Screen readers** | `aria-label="Our business ventures"` on carousel, `aria-live="polite"` for current slide |
| **Color contrast** | Forest on ivory (WCAG AA large text), gold on dark forest for headings, ivory on forest-deep |
| **Focus visible** | Default focus styles preserved, no custom removal without replacement |
| **Inert non-active cards** | `inert` prop on carousel side cards removes from tab order |
| **Semantic HTML** | `<section id="...">`, `<header>`, `<nav>`, `<p>`, `<blockquote>` all used appropriately |
| **Skip links** | Fixed in navbar: `Skip to content` link targets `#main` |
